Codes for generate cavity transmission spectra and related plots of bilayer magnetic thin film inside an electromagnetic cavity.

The file <a href="https://github.com/solihinn17/bilayer-cavity-magnonics/blob/main/calc.ipynb">calc.ipynb</a> contains notes and codes for calculating the transmission spectra and some other plots of bilayer magnetic thin film inside an electromagnetic cavity
